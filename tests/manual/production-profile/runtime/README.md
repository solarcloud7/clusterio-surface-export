# Docker acceptance runtime

This recipe belongs to the [packaged installation and backup fixture](../README.md).
It supplies isolated controller and host images, settings and world provisioning
for the test. It is not a supported operator deployment or a replacement for
Clusterio or clusterio-docker.

Administrators [install the npm plugin into Clusterio](../../../../docs/admins/deployment.md).
Keep historical fixture pins and failure evidence scoped to their recorded tests.
