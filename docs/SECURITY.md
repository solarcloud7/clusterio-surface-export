# Security reports

Use [GitHub private vulnerability reporting](https://github.com/solarcloud7/clusterio-surface-export/security/advisories/new) for authentication bypasses, exposed credentials, remote execution or other security vulnerabilities. Do not open a public issue with exploit details or secrets.

Include the affected plugin, Clusterio and Factorio versions, installation method, impact and reproduction steps. Remove unrelated credentials and personal information from diagnostic attachments.

Use [Issues](https://github.com/solarcloud7/clusterio-surface-export/issues/new/choose) for ordinary transfer and installation bugs. The [verification limits](../README.md#verification-and-limits) describe the tested deployment scope.
